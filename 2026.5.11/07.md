## 1. Pandas
### 1.1 DataFrame
```python
pandas.DataFrame(data=None, index=None, columns=None, dtype=None, copy=False)
```
- data : dictionary, list...
- index and columns : default value 0,1,2...
- dtype : change the data type of the data
- copy : default False. 若不拷贝，当数据源改变时，DataFrame同步改变
### 1.2 DataFrame Function  
**access columns** : ```df['A', 'B' ]```
**access rows** : 
```python
df.loc['i', 'ii']  # select by row name
df.iloc[0:2] # select by position
```
**select data from multiple rows and cols** : ```df.loc['i':'ii', ['A', 'C']]```  
**brief information** : ```df.info()```  
**get stats info** :
```python
df.describe()  # on numerical cols
df.describe(include = "o")  # on object cols
```
### 1.3 DataFrame Attributes
| Attribute | Description |
|:---- |:---- |
| **`DataFrame.index`**   | **It gives the Range of the row index** | 
| **`DataFrame.columns`** | **It gives a list of column labels** |
| **`DataFrame.dtypes`**  | **It gives column names and their data type** | 
| **`DataFrame.values`**  | **It gives all the rows in DataFrame** |
| **`DataFrame.empty`**   | **It is used to check if the DataFrame is empty** | 
| **`DataFrame.size`**    | **It gives a total number of values in DataFrame** |
| **`DataFrame.shape`**   | **It gives a number of rows and columns in DataFrame** | 
### 1.4 DataFrame modification
**add a column** : ```df.insert(loc = position, column = name, value = )```  
**drop a column** : ( two ways )
```python
df.drop(columns= ["Sex"], inplace = True)
df = df.drop(columns= ["Sex"])
```
### 1.5 Process Data
#### level 1 aggregation -- what is the average of age
```python 
df["Age"].mean() # min, max, count, size
```
#### level 2 aggregation -- what is the average of age in each city
```python
df.groupby("City")["Age"].mean()
```
#### level 3 aggregation -- the average of age per city and per sex
```python
print(df.pivot_table(index = "City", columns = "Sex", values = "Age", aggfunc = "mean"))
# index : first group
# columns :second group
```
### 1.6 Logical Operators in Panda
| Operator | Symbol | Example |
|----------|--------|---------|
| AND | `&` | `(df['A'] > 2) & (df['B'] < 10)` |
| OR | `\|` | `(df['A'] > 2) \| (df['B'] < 10)` |
| NOT | `~` | `~(df['A'] > 2)` |
| XOR | `^` | `(df['A'] > 2) ^ (df['B'] < 10)` |

## 2. Data Exploration
### step1 : Read Data
**read the data** : ```df = pd.read_csv(file_path)```  
**preview some lines** : ```data.head(5)``` ```data.tail(5)```
### step2 : Data Cleaning  
**select columns** : use ```df = df[]``` or ```.drop()```
```python
df_num = df_low.select_dtypes( include = 'number') # select numerical columns
```
**rename columns** :
```python
cols_to_rename = {'floorAreaSqM' : 'sqm' ,
                  'currentEnergyRating' : 'energy',
                  'history_price' : 'price'}
df = df.rename(columns = cols_to_rename)
```
**missing value** :
check for missing values
```python
print(df.isnull().sum()) 
```
> .isnull() 将NaN替换为True，将非空替换为False
> .sum() 按列求和，True为1，False为0

missing values in numerical cols ( replace NaN with mean )
```python
sqm_avg = df['sqm'].mean()
df['sqm'].fillna( sqm_avg )
```
missing values in categorical cols ( replace NaN with the most frequent value )
```python
energy_v = df['energy'].mode() #most frequent value
df['energy'].fillna( energy_v )
```
simple approach : remove all the rows with missing values
```python
df = df.dropna()
```
**type conversion**
```python
df['bathrooms'] = df['bathrooms'].astype(int)
```
convert numerical col to categorical ( two ways )  
*cut and qcut*
> ```python
> numbers = [1,3,5,8,9,18,19,20,70]
> # cut create equal-ranged groups
> pd.cut(numbers , bins = 3, lables = ['L', 'M' , 'H'])
> # qcut create equal-sized groups
> pd.qcut(numbers , q = 3 , labels = ['L' , 'M' , 'H'])
> ```
*normal way*
```python
def my_energy_map(x):
    if x in ['A', 'B', 'C'] :
        return 'efficient'
    else :
        return 'not efficient'
df['energy'] = df['energy'].apply( my_energy_map)
```
### step3 : Data Exploration
#### numerical columns
*pandas style*
```python
df_low["price"].plot( kind = 'box'); # 箱型图，展示数据特征（中位数等）
df_low['price'].plot( kind = 'hist'); # 频率分布直方图
```
*seaborn style*
```python
sns.boxplot(data = df_low , x = 'price');
sns.histplot( data = df_low , x = 'price');
sns.displot(data = df_low, x = 'price',kde = True); # 直方图加密度估计曲线（kde）
```
#### categorical columns
*pandas style*
```python
df['energy'].value_counts().plot( kind = 'bar');
```
*seaborn style*
```python
sns.countplot( df['energy']) ;
sns.barplot( df['energy'].value_counts()); # 效果相同，推荐第一种
```
#### bivariate plots
*pandas style*
```python
df_low.plot( kind = 'scatter', x = 'sqm' ,y = 'price');
```
*seaborn style*
```python
sns.scatterplot( data = df_low , x = 'sqm' , y = 'price');
sns.boxplot(data = df_low , x = 'energy' , y = 'price');
sns.boxplot( data = df_low , x = 'energy' , y = 'price', hue = 'tenure'); # 根据tenure再分组
```
#### correlation plot
```python
sns.heatmap(df_num.corr(), annot = True ,fmt = '.1f' ,cmap = 'Blues')
# annot : see the values
# fmt : format of the values : 1 floating point
# cmap : color map ( you can select from a range of color map)
```
