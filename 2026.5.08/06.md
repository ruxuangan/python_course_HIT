## 1. Package : matplotlib
import matplotlib.pyplot as plt

**Figure** 代表整个窗口/页面。一个 Figure 可以包含多个 **Axes (Subplots)**。
**创建方式**：
```python
fig, ax = plt.subplots(nrows=2, ncols=4)     # 2行4列共8个subplots
```
**设置figure**
- `fig.tight_layout()` — 自动调整figure大小，防止重叠
- `figsize=(宽, 高)` — 设置画布尺寸

```python
fig, axes = plt.subplots(nrows=2, ncols=4, figsize=(10, 4))
fig.tight_layout()
```
**设置subplots**
```python
ax.set_xlim([0.5, 4.5])         # x轴范围
ax.set_ylim([-2, 8])            # y轴范围
ax.set_title("An Example Axes") # 标题
ax.set_ylabel("Y-Axis")         # y轴标签
ax.set_xlabel("X-Axis")         # x轴标签
```

## 2. Plotting function
```python
fig, ax = plt.subplots(nrows = 3 , ncols = 2 , figsize = (3,5))
ax[0][0].plot(x,y, linewidth = 2, color = "black", linestyle = ":"); # 折线图
ax[1][0].scatter(x, y);                                              # 点图
ax[1][0].bar(x,y);                                                   # 柱状图
```

## 3. Matplotlib language
### 3.1 Colors
| 方式 | 示例 |
|------|------|
| **单字母** | `'b'`蓝 `'g'`绿 `'r'`红 `'c'`青 `'m'`品红 `'y'`黄 `'k'`黑 `'w'`白 |
| **颜色名** | `"blue"` `"yellowgreen"` `"burlywood"` |

### 3.2 Linestyles
| 样式 | 说明 |
|------|------|
| `'-'` | solid 实线 |
| `'--'` | dashed 虚线 |
| `'-.'` | dashdot 点划线 |
| `':'` | dotted 点线 |
| `'None'` / `' '` / `''` | 不画线 |
